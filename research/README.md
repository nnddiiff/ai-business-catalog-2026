# Свободные ниши потребительских ИИ-продуктов в рунете

Каталог потребительских ИИ-продуктов, коммерчески работающих в США, с проверкой
наличия российского аналога. Цель — список того, что в рунете ещё не сделано.

Данные собраны 8 августа 2026 многоагентным прогоном `ru-ai-niche-gap`:
24 агента, 434 вызова инструментов, 709 тыс. токенов. Ошибок и пустых результатов нет.

## Результат в одну строку

**77 ниш проверено: 50 занято, 20 частично, 7 свободно. Из восьми лучших кандидатов
адверсариальную проверку пережили два.**

## Что выжило

| Ниша | Статус | Незанятый зазор |
|---|---|---|
| ИИ-интервьюер: автобиография голосом | устояла под атакой | Никто не ведёт **беседу** — все раздают анкету, составленную до разговора |
| Мобильный сканер бумажного фотоархива | устояла под атакой | Никто не снимает разворот альбома с автонарезкой на отдельные кадры |

Три ниши остались свободными, но до адверсариальной проверки не дошли из-за низкого
балла, и балл низкий по существу: озвученная аудиоистория предка бессмысленна без своей
базы архивных записей; ИИ-апелляции на отказы страховой построены на американской
частной медицине, в ОМС механизма денежной апелляции нет; детский 3D-принтер требует
железа, сертификации и китайских поставок.

## Что убито адверсариальной проверкой

Шесть кандидатов из восьми. Во всех случаях первый агент искал по формулировке задачи,
а скептик заходил с другой стороны и находил аналог:

| Ниша | Чем убита |
|---|---|
| ИИ обзванивает пожилого родителя, собирает мемуары | `memofamily.ru`, «Амбистелла» |
| Цифровой сейф наследия | `legacynet.ru`, `lastnote.io`, «Цифровой сейф» нотариата |
| ИИ-тренажёр чтения вслух для ребёнка | Шесть приложений в App Store RU через iTunes Search API |
| Приватный семейный дневник ребёнка | «Бебидейка» — 249 ₽/мес, 1490 ₽/год |
| Комикс с именинником в главной роли | `vibecomics.app`, `storiko.com/ru`, `comibook.ru` |
| Оцифровка рукописных рецептов | `mrcook.app/ru` с полной русской локализацией |

Практический вывод из этой таблицы: пустота в рунете почти всегда мнимая и держится на
том, что искали не тем словом или не в том каталоге. Любую нишу из списка свободных
надо перед запуском атаковать так же — 6 из 8 не выживают.

## Метод

Четыре фазы, каждая проверяет предыдущую:

1. **Каталог США.** Шесть агентов по семьям категорий (подарки, память, отношения,
   дети, быт, творчество) плюс два агента разведки по российской инфраструктуре и праву.
2. **Свод.** Дедупликация и канонизация: 17 позиций выброшено, осталось 77.
3. **Проверка рунета.** Семь агентов по корзинам ниш ищут российский аналог по вебу,
   телеграм-каталогам, VK Mini Apps, RuStore, App Store, маркетплейсам.
4. **Опровержение.** Восемь скептиков с обратной задачей — найти аналог и убить нишу.

## Ограничения данных

- Каталог строился по фильтру «ИИ в ядре продукта». Коллективные видеопоздравления,
  цифровые приглашения и подарочные карты с видео выброшены на этом шаге — это
  отбраковка по заданию, **а не доказанная занятость ниши**. Вывод предыдущего
  исследования (июль 2026) о свободе этой ниши данным прогоном не проверялся и не отменён.
- Две корзины из семи работали в дефиците поиска (лимит запросов) и частично
  перебирали прямые ссылки вместо поиска: семьи «дети и учёба» и «отношения и
  компаньоны». Их вердикты менее надёжны. Корзина по отношениям при этом дала 8 занято
  из 11, то есть смещения в сторону ложного «свободно» не показала.
- Финансовые показатели западных игроков — в основном сторонние оценки (Sensor Tower,
  Latka, Kona Equity, Starter Story), между собой расходящиеся. Официально
  подтверждённых цифр выручки мало.
- Данные актуальны на 8 августа 2026. Рынок ИИ-продуктов меняется быстро, а телеграм-
  и VK-экосистемы позволяют нишевому продукту появиться ниже порога поисковой видимости.
