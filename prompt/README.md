# prompt/

Задание для следующего исследования и разведданные под него.

| Файл | Что это |
|---|---|
| [PROMPT.md](PROMPT.md) | Готовый к запуску текст задания: таксономия из 22 семей, поля по каждой идее, критерии доказательности, каналы поиска |
| [landscape-2026.md](landscape-2026.md) | Разведка на 10 запросов: что происходит в девяти категориях, с компаниями, цифрами и ссылками |

## Зачем это

Предыдущее исследование (`../research/`) отвечало на узкий вопрос: какого цифрового
продукта самообслуживания за 300–2000 ₽ нет в рунете. Три фильтра — «только
самообслуживание», «потолок чека», «ИИ в ядре продукта» — сделали невидимым целый класс
бизнесов: агентства, бутики, фабрики, инфраструктуру, обвязку. Новое задание эти фильтры
снимает явным запретом на их возврат.

Цель — ширина. На выходе нужен индекс идей с проверяемыми цифрами, каждая из которых
дальше изучается отдельным проходом.

## Порядок работы

1. Прочитать `landscape-2026.md` — чтобы не переоткрывать известное.
2. Запустить `PROMPT.md`.
3. Полученный индекс разбирать по одной идее.

Справочные данные по российскому контуру уже собраны и переисследованию не подлежат:
`../research/06-suverennyj-internet.md` (суверенный интернет, MAX, VK, Telegram, сторы)
и `../research/07-stek-i-pravo.md` (модели, GPU, платежи, 152-ФЗ, НДС, трафик).
