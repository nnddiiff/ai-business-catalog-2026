# Каталог ИИ-бизнесов 2026

Каталог бизнесов, построенных на ИИ и вокруг ИИ, по состоянию на 8 августа 2026,
с проверкой того, есть ли у каждой идеи российский аналог. **439 идей в 23 семьях.**

**Смотреть: https://nnddiiff.github.io/ai-business-catalog-2026/**

Сайт рассчитан на телефон: поиск по названиям, игрокам и сути, фильтры по вердикту
и по семье, карточка идеи на все шестнадцать полей, сводные разборы отдельными
разделами.

## Как читать вердикт по России

«Свободно» здесь означает «аналог не найден», а не «его нет». Скептики проверили
138 таких вердиктов и изменили 133 — всегда в сторону «занято». Прежде чем
опираться на вердикт, смотрите раздел «Проверка скептиков»: там перечислено, что
именно опровергнуто и чем.

## Как пересобрать сайт

```bash
python3 site/build.py     # читает catalog/, пишет docs/
```

Зависимостей нет, только стандартная библиотека Python. Сборщик разбирает карточки
на поля, переводит markdown в HTML, разворачивает широкие таблицы в раскрывающиеся
блоки и разрезает данные на лёгкий индекс плюс файл на каждую семью, чтобы первая
загрузка на телефоне оставалась небольшой.

## Ограничения данных

Прогон остановлен на 93% недельного лимита, поэтому не выполнены четыре сквозных
прохода по российским каналам — сторы приложений, vc.ru и Habr, корпоративный контур
CNews и TAdviser, каталоги телеграм-ботов и VK. Три отдельные охоты за провалами не
запускались: сводный раздел собран из семейных файлов. Семь семей не получили
скептика. Финансовые показатели западных игроков — в основном сторонние оценки,
расходящиеся между собой; дата рядом с цифрой означает день снятия данных.
